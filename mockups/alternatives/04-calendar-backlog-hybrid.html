Option 4: Calendar + Backlog Hybrid

✓ Advantages

  • • WEEK-level scheduling (no day noise)
  • • Visual capacity planning (see overloaded weeks)
  • • Drag-drop scheduling from backlog
  • • "Current week" is crystal clear
  • • Backlog is first-class (not hidden)
  • • Agent workflow: "What's scheduled this week?"
  • • Balances timeline + flexibility

✗ Disadvantages

  • • Still needs "week" concept (though simpler than day)
  • • No phase/milestone grouping visible
  • • Capacity planning needs estimates on every ticket
  • • Drag-drop needs JS implementation
Key Change: DELETE Phase, Sprint, Day models. Keep only Week model. Ticket.scheduledWeekId is the link. Weeks are numbered (W1, W2...) with date ranges. "Current week" = Week.startDate <= now <= Week.endDate. Much simpler than 4-level hierarchy!
