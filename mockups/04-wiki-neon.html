Quick Start Guide

Get up and running with ProjectPulse in under 5 minutes

1 Installation

ProjectPulse can be installed via npm, yarn, or pnpm. We recommend using the latest LTS version of Node.js (v18 or higher).

Terminal 
# Using npm
npm install -g projectpulse

# Using yarn
yarn global add projectpulse

# Using pnpm
pnpm add -g projectpulse

Pro Tip

Install ProjectPulse globally for easier access to CLI commands from any directory.

1.1 Create a New Project

Once installed, you can create a new project using the init command:

Terminal 
projectpulse init my-awesome-project
cd my-awesome-project

1.2 Configure Settings

Edit the pulse.config.json file to customize your project settings:

pulse.config.json 
{
  "project": {
    "name": "My Awesome Project",
    "version": "1.0.0"
  },
  "agents": {
    "enabled": true,
    "defaultPersona": "code-reviewer"
  },
  "integrations": {
    "github": true,
    "slack": false
  }
}

2 Setting Up Agents

ProjectPulse agents are AI-powered assistants that help automate various tasks. Let's activate your first agent:

Terminal 
projectpulse agent activate code-reviewer

Available agent personas:

🔍

Code Reviewer

Reviews code for best practices, bugs, and improvements

🐛

Bug Hunter

Systematically finds and diagnoses bugs in your codebase

🏗️

Feature Architect

Designs new features and system architecture

🛡️

Security Auditor

Audits code for security vulnerabilities

3 Creating Your First Issue

Issues are the core of ProjectPulse. They represent tasks, bugs, or features that need attention.

Terminal 
projectpulse issue create \
  --title "Fix login form validation" \
  --priority high \
  --agent code-reviewer

Success!

Your first issue has been created. The Code Reviewer agent will automatically analyze it.
