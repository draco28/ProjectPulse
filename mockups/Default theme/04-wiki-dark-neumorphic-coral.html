1 Installation

ProjectPulse can be installed via npm, yarn, or pnpm. We recommend using the latest LTS version of Node.js (v18 or higher).

Terminal 
# Using npm
npm install -g projectpulse

# Using yarn
yarn global add projectpulse

# Using pnpm
pnpm add -g projectpulse

Pro Tip

Install ProjectPulse globally for easier access to CLI commands from any directory.

1.1 Create a New Project

Once installed, you can create a new project using the init command: 

projectpulse init my-awesome-project
cd my-awesome-project
