FSM Authority not properly replicated in combat

Opened by Moksha Dev 2 hours ago Updated 30 minutes ago

Description

Combat state machine experiencing desynchronization between client and server during rapid state transitions. The FSM authority is not being properly replicated, causing clients to show incorrect combat states.

Steps to Reproduce:

  1. Start combat with multiple enemies
  2. Perform rapid state transitions (attack → dodge → attack)
  3. Observe client-side state differs from server

Expected Behavior:
FSM state should be synchronized across all clients immediately upon state change on the server.

Actual Behavior:
Clients show stale states for 100-300ms, causing animation and gameplay desync.

Relevant Code 

// CombatStateComponent.cpp
void UCombatStateComponent::ServerSetState(ECombatState NewState)
{
    if (HasAuthority())
    {
        CurrentState = NewState;
        // Missing replication trigger here!
        OnStateChanged.Broadcast(NewState);
    }
}
