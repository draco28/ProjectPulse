# Workflow 02 — Feature Development

Prereqs: Run Workflow 01 first.

Steps:

1. Architect plan → next-js-expert/prisma-expert/react-expert
2. Implement feature (server-first, services layer, Prisma)
3. Add tests (unit + integration + optional E2E)
4. Audit security
5. Verification Gate (Workflow 11)
6. Docs-first commit, then code

Acceptance:

- Quality gates pass; coverage ≥80% new code
- Evidence attached at Step 4.5
