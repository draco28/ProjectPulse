# Workflow 03 — Bugfix & Regression

Steps:

1. Reproduce and write failing regression test (Red)
2. Implement minimal fix (Green)
3. Refactor safely (Refactor)
4. Run full test suite; ensure coverage preserved
5. Verification Gate (Workflow 11)
6. Update docs if behavior changed; commit in order

Evidence:

- Failing test then passing test output
- Linked issue and files changed
