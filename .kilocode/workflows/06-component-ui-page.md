# Workflow 06 — Component / UI / Page

Steps:

1. Use Server Components by default
2. Create client components only for interactivity/hooks
3. Data fetched on server; pass props to client
4. Add rendering + hydration tests; basic a11y checks
5. Verification Gate (Workflow 11)

Acceptance:

- No unnecessary client components
- No hydration mismatch; basic a11y passes
