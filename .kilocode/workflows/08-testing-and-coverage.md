# Workflow 08 — Testing & Coverage

1. Identify scenarios from PRD/SRS
2. Unit test services/utils; integration test routes; E2E for key flows
3. Achieve ≥80% coverage; report gaps
4. Verification Gate (Workflow 11)

- pnpm test green; coverage gate met; regressions captured
