## Week 2: Health Monitoring (19 points)

### Day 8-9: Scanner Foundation (US-116, US-117: 8 points)

**Tasks**:
1. Task 18: Create Prisma models: HealthScanner, HealthFinding, HealthScore
   ```prisma
   model HealthScanner {
     id        String   @id @default(uuid())
     projectId String
     scanType  String   // semgrep, eslint, lighthouse, axe-core
     lastRunAt DateTime?
     findings  HealthFinding[]
   }

   model HealthFinding {
     id         String   @id @default(uuid())
     scannerId  String
     severity   String   // critical, high, medium, low
     message    String
     filePath   String?
     lineNumber Int?
     category   String   // security, quality, performance, accessibility
     scanner    HealthScanner @relation(fields: [scannerId], references: [id])
   }

   model HealthScore {
     id          String   @id @default(uuid())
     projectId   String
     overallScore Float   // 0-100
     securityScore Float
     qualityScore  Float
     performanceScore Float
     accessibilityScore Float
     calculatedAt DateTime @default(now())
   }
   ```

2. Task 19: Create health_monitoring_foundation migration
   - Add 3 new models
   - Add indexes on projectId, scanType, severity
