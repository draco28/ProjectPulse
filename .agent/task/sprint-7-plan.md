### Day 11: Health Score Calculation (US-119: 5 points)

**Algorithm** (Weighted Formula):
```typescript
// lib/health/score-calculator.ts
function calculateHealthScore(findings: HealthFinding[]): HealthScore {
  // Score = 100 - (CRITICAL×10 + HIGH×5 + MEDIUM×2 + LOW×1)
  const securityScore = calculateCategoryScore(findings, 'SECURITY');
  const qualityScore = calculateCategoryScore(findings, 'CODE_QUALITY');
  const performanceScore = calculateCategoryScore(findings, 'PERFORMANCE');
  const accessibilityScore = calculateCategoryScore(findings, 'ACCESSIBILITY');

  // Weighted average: security 40%, quality 30%, perf 20%, a11y 10%
  const overallScore = securityScore * 0.4 + qualityScore * 0.3 + performanceScore * 0.2 + accessibilityScore * 0.1;

  return { overallScore, securityScore, qualityScore, performanceScore, accessibilityScore };
}
```

## Risk Assessment

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|------------|
| JSDoc parser edge cases | High | Medium | Start with TypeScript only, defer Python |
| Scanner false positives | Medium | High | Implement false positive marking |
| Lighthouse/axe performance | Medium | Medium | Run scans async, cache results 24h |
| Git merge conflicts | Low | Low | Wiki stored in DB (single source of truth) |
| Semgrep installation issues | Medium | Medium | Use Docker container (isolated) |
| ESLint config conflicts | Low | Medium | Use project's existing .eslintrc |

**High-Risk Items**:
1. **JSDoc Parser Complexity** (US-107: 8 points)
   - **Mitigation**: Focus on TypeScript (80% of codebase), defer JavaScript/Python
2. **Scanner Integration Performance** (US-116-118: 11 points)
   - **Mitigation**: Run scans async, cache results, prioritize Semgrep + ESLint first
